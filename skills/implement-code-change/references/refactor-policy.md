# Refactor policy

Read `.agents/refactor-policy.md`; stop for [setup-repo](../../setup-repo/SKILL.md) if missing.
Follow it, allowing only explicit, change-scoped user overrides. Improve local reasoning, not
line counts. Complete consumer migrations and remove obsolete references and paths unless
compatibility requires them. Verify coherence beyond passing tests; document retained
compatibility. Discuss ineffective refactors before continuing.
