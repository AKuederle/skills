# Design it twice

For consequential interface choices, state current behavior/constraints/ownership, sketch at least
two materially different interfaces with realistic callers, and compare depth, locality, valid
states, lifetimes, and caller knowledge. Recommend the smallest sufficient design with tradeoffs,
without speculative flexibility. Independent subagent sketches are optional when authorized/useful;
respect model constraints. Return to [implementation](../implement-code-change/SKILL.md) after
choosing.
